# Solution

Executable baseline for the current CLI and harness.

## Not Yet Validated By Harness

- In production the test battery is generated by an LLM prompt recipe
  (`compute_wpp_tests_generated`). Creating a prompt / LLM-generation recipe is
  not expressible through the current CLI, so the battery is supplied as the
  `wpp_test_cases` dataset and imported. The review is built and loaded but not
  run, so per-test scores are not produced.

```bash
dku agent-review create wpp_strategist_review -P {project}
dku agent list -P {project} -o json | jq -r '.[] | select(.name=="wpp_campaign_strategist") | .id' > /tmp/{project}_wpp_review_agent.txt
dku agent-review set-agent wpp_strategist_review --agent "$(cat /tmp/{project}_wpp_review_agent.txt)" -P {project}
dku agent-review set-llm wpp_strategist_review --llm "$(dku llm list -P {project} -o json | jq -r '.[0].id')" -P {project}
dku agent-review add-trait wpp_strategist_review --name BrandAlignment --description "Recommendations align with the brand guidelines" --criteria "Do the recommendations align with the brand's documented guidelines and tone?" -P {project}
dku agent-review add-trait wpp_strategist_review --name ChannelMixJustified --description "The recommended channel mix is justified by performance data" --criteria "Is the recommended channel mix justified by the campaign performance data?" -P {project}
dku agent-review add-trait wpp_strategist_review --name SourcesCited --description "Brand and trend sources are cited" --criteria "Does the brief cite the brand and trend sources it relied on?" -P {project}
dku agent-review add-trait wpp_strategist_review --name GovernanceFlagged --description "Campaigns over the 5000000 euro budget threshold are flagged for governance review" --criteria "If the campaign budget exceeds 5000000 euro is it flagged for governance review?" -P {project}
dku agent-review add-trait wpp_strategist_review --name ScopeDiscipline --description "Stays within campaign strategy scope" --criteria "Does the agent stay within campaign strategy scope and refuse out-of-scope requests?" -P {project}
dku agent-review import-tests wpp_strategist_review --dataset wpp_test_cases --query-column query --reference-column reference --expectations-column expectations -P {project}
```
