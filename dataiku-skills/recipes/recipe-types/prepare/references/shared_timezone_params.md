# Shared Timezone Params

Use this reference for timezone-related params reused across date/time prepare processors.

## Param Contract

| Param | Domain | Allowed values | Notes |
| --- | --- | --- | --- |
| `timezone_id` | `enum` | `UTC` (default) \| `extract_from_column` \| `extract_from_ip` \| supported static timezone values | Timezone mode: fixed timezone, timezone from column, or timezone inferred from IP column. |
| `timezone_src` | `string<column_name>` (conditional) | Any valid column name | Required when `timezone_id = extract_from_column` or `timezone_id = extract_from_ip`. |
