# Alteryx collapse triggers — the Phase-2 collapse pass

The migration skill's "N source steps → far fewer recipes" rule requires a collapse pass after the 1:1 draft. Each row is a pattern; find it → collapse before showing the plan. Format: **pattern | DSS recipe(s) + the one non-obvious trick (+ at most one crux snippet) | ratio**. For the full worked recipe of any row, open the leaf file in its last cross-ref.

| Trigger pattern | DSS collapse + the one trick | Ratio |
|---|---|---|
| "Zero-pad date before parse" macro (`TextToColumns → Formula(padleft+concat) → Select(drop) → DateTime`) | One Prepare: `DateParser → DateFormatter`. DSS `DateFormatter` zero-pads via the format pattern (`MM/dd/yyyy HH:mm`) — the split/padleft are redundant. tools-state-parsing.md | 4→1 |
| **N sequential Joins each adding one input** — `JoinMultiple`, N stacked `Join` lookups onto a fact spine, or N stacked `AppendFields` (cartesian) building a combination grid | **ONE multi-input Join.** Equi: `create-join -i spine -i a -i b … -k spinekey -k 1:akey -k 2:bkey`; key on a non-spine table → set `joins[i].table1`. Cross grid: `-j CROSS`. Graph backstop: `../references/flow-collapse.md` § Fuse a sequential join chain. | N→1 |
| Per-input Prepare/`AlteryxSelect` before a `Union` — adding a literal `source="X"` tag, OR only renaming to unify first-col names | Source-tagging: `create-stack --origin-column source` (the whole per-input layer disappears). Rename-only (not source-tagging): keep the rename as the SOLE per-input Prepare step. | N+1→1 |
| `Join(3-out) all re-Union`ed into ONE table — "merge full set, tag which side" (schema/list compare, two-list reconcile, set diff) | **One FULL OUTER join + one Prepare.** `create-join -j FULL -k key --engine SQL` gives matched + left-only + right-only in one pass = the three Alteryx outputs; Prepare shapes (`if(isBlank(...))`). ⚠ FULL OUTER needs SQL — engine gotcha + Stack workaround: tools-join-reshape.md § Join. | 8→4 |
| `RegEx(SplitToRows) → Filter → Summarize(key,header,Count) → CrossTab(Sum) → null→0 → AddTotalRowColumns.yxmc → Sort` — build key×header incidence matrix with row total | **2 Prepare + 1 Pivot.** Trick: Pivot's **default global count IS the per-cell count and auto-fills 0**, so Summarize+CrossTab+null→0 all collapse. `create-pivot -r key -c header --value-limit NO_LIMIT`; Total via `replace((numval(a)+…)+"", /\.0$/, "")` (keeps `bigint`). Drop the presentation Sort. tools-join-reshape.md § CrossTab | 8→3 |
| Reshape whose only consumer immediately re-aggregates — `Union → Transpose → Summarize` (per-key aggregates) or `Summarize → CrossTab` (fan a per-key value into N cols for a join) | Compute the per-key/per-modality aggregate **inline in the upstream Prepare** (one `add-formula` per output key/modality); the reshape disappears entirely. Also dodges the CrossTab modality-scan blocker (tools-join-reshape.md § CrossTab). | →0 extra |
| `Sort → MultiRowFormula(running total) → Summarize/CrossTab` where the running total's ONLY consumer is the per-group **total** (last cumulative value) — "cumulative-on-group-basis" (YTD per account) | The running total IS the group `SUM` — **drop Sort + MultiRowFormula.** One `create-pivot -r <group> -c <category> -v <value> --agg-type SUM`. Pre-filter junk by a **data predicate** not row number (`endsWith(strval("AGE_CATEGORY"),"yr")`). (Contrast `RunningTotal→Window` when you need per-row running values.) | 14→2 |
| `Sort → MultiRowFormula(running max prior Exit) → flag-new-group → cumsum → Summarize → Summarize(sum)` — "**merge overlapping intervals / total covered time**" (gaps-and-islands; room occupancy, uptime, coverage) | **Sweep-line, visual not Python:** Window cummax(exit) partitioned+ordered by start (frame UNBOUNDED PRECEDING→CURRENT), then a 2nd Window `lag(cummax,1)` → `prev_max`. **One Window can't get `prev_max`** — a "1 PRECEDING"-ending frame is clamped to include the current row; cummax-then-lag is the visual form of a strictly-preceding running aggregate. Then Group summing each interval's uncovered part: `if(isBlank(prev_max), exit-enter, max(0, exit-max(enter,prev_max)))`. No island-id cumsum. `../../dku-cli/references/visual-recipe-payloads.md` § Window | ~6→4 |
| `Sort → Sample(first/last 1 per group)` or `Summarize(Max/Min by group) → Join` back — "**which row holds the per-group max/min**" (argmax/argmin) | **One `create-topn --partition-key G -n 1 --sort-col V:desc`** (max) / `--bottom 1` (min) — returns the ENTIRE winning row per group; no Summarize, no join-back. Two TopN + a Join on the group key = per-group "max…min…" report. Attach a whole-partition stat first via `create-window … --frame-unbounded`. | Summarize+Join→1 |
| `Transpose → Filter → Formula → Union → Summarize → … → CrossTab` — "**half-distribution mirrored into signed ± columns**" (Galton/Plinko, ±histograms) | **Prepare → Prepare → Group.** Trick: mirror AND pivot collapse into inline symmetric bins — per signed bin `c∈−K..K`, `c=if(pos==abs(c), val_norm, 0)` (the +c/−c pair shares `abs(c)`), then `create-group -k level` summing every bin. Drops the Union-mirror, the CrossTab (modality blocker never bites), the Summarize. `--rename c_sum:-4` writes signed names. | ~8→3 |
| `CrossTab → Filter(column-existence) → Summarize(count)` — pivot wide, filter "all these cols present", count | Two `create-group`s, no Pivot. First: `computedColumns` one indicator per modality (`is_food=if(MealDealItem=="Food",1,0)`), `--agg max` per key. Second (global, `keys:[]`): existence `pmd=if(has_food+has_drink+…==N,1,0)`, `count(*)` denom + `sum(pmd)` numer. | 3→2 |
| `BatchMacro` iterating an op over a control parameter | Per-key iteration as a CROSS/equi-join on the control column. Macro body (5–10 tools) → 1 join + 1 prepare. | macro→2 |
| `WeightedAvg.yxmc` (or any per-group `sum(x*w)/sum(w)`) | One `create-group` `computedColumns` (`Weighted=X×W`) summing both, then one Prepare to divide. | macro→2 |
| `Filter(cond) →[T] Formula(set col=fixed) → Union ←[F] Filter` — "**patch a subset of rows, then merge back**" | **One `add-formula`** in an existing Prepare: `col = if(<cond>, <fixed>, strval("col"))`. Filter+Formula+Union all disappear. | 3→0 |
| `Summarize(distinct) → Sort DESC → Sample(First N) → RecordID → Join(back)` — "**dense-rank top-N**" (`(value,rank)` lookup, joined back) | One `create-window --compute denseRank::rank --order-key value:desc` (no partition), then Prepare `FilterOnNumericalRange rank∈[1,N]` + rename. `denseRank` is the native rank-distinct fn. | 5→2 |
| `Transpose → MultiRowFormula → CrossTab → JoinMultiple → Select → Transpose` — round-trip to attach moving-average col(s) before re-melting | **Stay long:** fold once with imputation → Window for lags → Prepare boundary-coalesce+average → emit as a Stack of per-stream projections. Wide round-trip + JoinMultiple disappear. | 6→4 |
| `MultiRowFormula <OtherRows>Nearest</OtherRows>` (boundary fills with partition first/last value) | Window's natural `Lag(col,k)` returns null at boundary — DOES NOT match. Window with explicit `Lag` per offset **PLUS `FirstValue` over partition**, then Prepare `if(isBlank(col_lag_k), col_first, col_lag_k)` per offset. tools-state-parsing.md | (rule) |
| `Sort → RunningTotal → MultiRowFormula` referencing `[Row-1:RunTot_X]` with `NumRows=1` — "**greedy allocation / fill-by-priority**" (capacity-constrained ranking, top-K-by-budget) | One `create-window` (cumsum, partition+order) + one `add-formula` — the lag column is redundant by algebra (tools-state-parsing.md § RunningTotal collapse hint); Sort redundant (Window `--order-key`). | 3→2 |
| `MultiColumnFold` step where input has nulls in any folded column | Fold silently DROPS null-value rows — pre-impute (or sentinel-fold) BEFORE the fold in the SAME Prepare: tools-join-reshape.md § Transpose | (ordering rule) |
| `Formula(split code) → MultiRowFormula(forward-fill suffix) → MultiRowFormula(disambiguate via [Row+1])` — "**compact-encoded sequence, neighbor-disambiguated**" (`J07,F,M,…,J08` where year shows only at January) | ONE Window + ONE Prepare. Trick: **cumulative-max-over-string forward-fills the year** (`''<'07'<'08'` lexicographically — works only for monotonic suffixes): `--compute 'max:suffix:'`; plus `--compute 'lead:letter:'` for the neighbor. Then Prepare cascades month name from `(letter, next_letter)`. `../../dku-cli/references/visual-recipe-payloads.md` § Window | 3→2 |
| **Wide survey/form → tidy long**: one row carries (a) fixed columns *whose header encodes the keys* (header = entity, cell = score) AND (b) K repeated optional entry-blocks of M cols. Goal: one row per `(respondent,key1,key2,value)` | **One Prepare (fixed) + K Prepare projections + Stack(optional) + Stack(union).** Fixed: `add-fold` then `ColumnSplitter separator=" with "` then rename `part_0/part_1`. **Keep-predicate differs per branch (bug-magnet):** fixed entries kept even when value blank (pre-`add-fill-empty` a sentinel before fold so `MultiColumnFold` keeps them, then find-replace back); optional kept on the **entity col present** (`entity != ""`), NOT the value col. | 16→7 |
| `DbFileInput(.txt one-col-per-line) → Filter → Formula(cascade-classify each line) → MultiRowFormula(RecordNumber++ on Company_Name) → CrossTab(Concat) → RegEx → Formula(coalesce)` — "**free-text records separated by blank lines, positional-field-per-line**" (mailing lists) | Cannot collapse below ~4 (cumsum is serial). (1) upload `.txt` as `(row_idx,line)`. (2) Prepare classify each line to a `Field` + flag `is_company`. (3) Window `--compute 'sum:is_company:' → RecordNumber`. (4) Group `-k RecordNumber`, one computed-col + agg `concat` + rename per output field, `--no-global-count`. (5) Prepare coalesce. **Trick:** GREL `match()` is WHOLE-string — anchor `/.*?(...)/` or it returns null (`../../dku-cli/references/formulas.md` § Strings). For trailing phone, check the `1-` prefix variant FIRST. | 8→4 |
| `DbFileInput(*.xls wildcard) → MultiRowFormula(row_within_file) → Formula(if Row==K) → Summarize(GroupBy FileName, Max)` — "**extract values at fixed (row,column) positions across many sheets**" | Pre-bake multi-file read offline (tools-core.md): one CSV `FileName,row_idx,F1..Fn`. ONE `create-group`: one `--computed-col 'value_at_K=if(numval("row_idx")==K, numval("Fc"), null):double'` per extraction (folds Formula), `-k FileName --agg value_at_K:max` (folds Summarize), group key + aggs renamed together. | 4→1 |
| Any chain whose net job is **parse structured text (HTML / JSON / XML-in-cell / free-text / encoded-string) into rows or columns** — `Replace→TextToColumns→…→CrossTab→Select`, `split("<")→RegEx→MultiRowFormula→CrossTab→Join×2`, `RegEx(split-to-rows)→Unique→RegEx→Summarize`, `FindReplace(dict)→TextToColumns→RegEx` | **One visual Prepare** (Python ONLY for rowspan/colspan or non-whole-row `<tr>`). Split on the **row-level** tag not the cell-level, filter wrapper rows, `RegexpExtractor`/`match()` per field — `match()` is whole-string, anchor `.*?` or it returns null. Per-shape patterns (HTML row/cell regexes; XML-in-cell wide 17→1; encoded-string fan-out 6→2 — a row-key regex replaces RecordID/Unique; free-text US address 5→1 — suffix dict baked into a regex alternation): tools-state-parsing.md § RegEx. Mega-field → pre-bake the row-split as upload-prep (overview.md § TextInput extraction). | 9→1 |
| `Summarize(per-partition aggregate) → Join(back on partition key, broadcast onto every row)` — "**compute a partition-wide stat and broadcast**" (imputation, normalization, ratio-to-group; `AvgNo0` = avg excluding zeros) | One `create-window … --frame-unbounded` `-k <partition>` + `--compute 'avg:val_no0:'` (lift zero-exclusion to `val_no0=if(val==0,null,val)` since AVG ignores nulls). **`--frame-unbounded` REQUIRED** — default Window is cumulative (only last row gets the partition value); it also sets `legacyUnboundedWindowStreamBehavior=true` (without which DSS still streams cumulatively). Multiple levels → separate Window recipes. `../references/flow-collapse.md` § Collapse a broadcast aggregate | 2→1 per level |
| Impute missing/zero cells with a **group statistic**, then aggregate — `Summarize(group mean) → Join(fill) → Summarize(SUM)`, or zero-impute-then-average across many metric cols per entity (store×dept sales) | **Skip the impute — it's algebra** whenever the post-fill aggregate is linear in the mean. *Fill-then-AVG = NO-OP:* post-fill mean = the non-zero/non-null mean, so just `nz_<m>=if(numval("<m>")==0,null,…)` (or null for blanks) → `Group --agg nz_<m>:avg` → Prepare totals/shares (stay WIDE, ~3 recipes; no fold/pivot/join). *Fill-then-SUM:* `filled_sum = Σ_nonnull × n / count_nonnull` — one `create-group --agg 'val:sum,count'` per measure (DSS `count` on a column = **NON-NULL** count; `n` row-count auto-added), one Prepare `val_sum * n / val_count`. Holds for SUM/AVG, **NOT MAX/MEDIAN** (those must impute). **NB** if the stage feeds `TS Forecast Factory` (ARIMA/ETS): not byte-reproducible R↔Python but **NOT a block** — Python statsmodels/pmdarima, validate by SHAPE (tools-predictive-ml.md § ARIMA). | 5→2 / ~28→3 |
| `Transpose → Self-Join(cross within partition) → Filter[M1]!=[M2] → … → CrossTab → Unique` — "**all unordered pairs of items per group**" (co-occurrences); reinvents C(N,2) | **Three recipes:** Prepare (wide→long w/ `@@EMPTY@@` sentinel via `add-fill-empty` so fold keeps rows + `add-fold`) → Self-Join `-i long -i long -k UserID -j INNER` → Distinct. **Trick:** in the self-join `set-settings` BOTH `virtualInputs[i].outputColumnsSelectionMode: MANUAL` with aliased `m_val` (default `AUTO_NON_CONFLICTING` SILENTLY drops one m_val), and `postFilter "left_val < right_val"` (strict `<` drops self-pairs AND dedups symmetric). `../../dku-cli/references/visual-recipe-payloads.md` | 11→3 |
| `Join(left=A,right=lookup1) + Join(left=A,right=lookup2) → Union` — "**fork-join-union with two heterogeneous lookups**" (each row appears once with EITHER set populated) | **Stack-then-single-join.** Trick: pre-tag each lookup with an origin col AND its role-specific column **already named for the final schema**, **Stack the lookups first** (`--mode UNION` — missing cols → null), then **one Join** of source × unioned lookup. | 7→4 |
| `Sample(First 1) → Formula(row-0 stamp) → AppendFields(cartesian) [+ Sample(skip headers) → DynamicRename → MultiRowFormula(fill category) → Filter]` — "**messy spreadsheet: embedded headers + global stamp + category fill-down**" | **ONE Prepare, fully visual:** extract the stamp + `UpDownFiller` it; derive the category col + `UpDownFiller`; filter data rows; rename + drop. **Trick: only NULL triggers `UpDownFiller`** — return `null` not `""` (`../../dku-cli/references/prepare-processors.md` § UpDownFiller). | 7-8→1 |
| `MultiRowFormula(fill header) → RecordID → Transpose → … → CrossTab` — "**wide layout with structured repeating column blocks**" (K brands × N metrics, sparse row-level group headers) | When block structure is **fixed-format** (same N metrics/block, same order — confirm at inventory): skip pivot/unpivot + cartesian range-join. | `RecordID → Transpose → DateTime → TextToColumns → CrossTab → Formula → GenerateRows(one row/day) → Filter(weekends) → Summarize → CrossTab` — "**count weekdays / business days in each range**" | **ONE Prepare, no row expansion.** `GenerateRows`-to-count is NOT a range-join (nothing to join).
